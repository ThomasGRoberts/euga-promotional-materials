Print at 100%, fold at the guides, and staple the tab/base overlap on the underside. The face-to-face fold forms the top ridge.
- [Download the current print flyer](print-flyer-current.pdf) — one-page, 8.5 × 11-inch PDF export of `flyer.html`.

All live products use the logo selected on the Program Branding page. The separate `-concept` PDF/PNG files are exports of the Stars + Globe option. The website carousel intentionally displays neither the wordmark nor an application CTA.

The TV banner uses local Europe map geometry and current program-city data. The office-door and table-tent prints reuse the flyer's earth-limb asset and the existing program-website QR. The office-door school logo uses `assets/Nunnlogo-transparent.png`, a transparent rendering of the existing institutional raster generated by `scripts/export_nunn_transparent.py`. Regenerate the affected PDFs after changing their HTML/CSS, shared logo, or content. Both table-tent QRs and the office-door QR decoded to `https://inta.gatech.edu/europeglobal` in the rendered print proofs.
