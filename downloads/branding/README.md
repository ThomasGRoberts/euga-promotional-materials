# Program wordmark exports

These files are generated from the approved canonical source at [`assets/branding/program-wordmark.svg`](../../assets/branding/program-wordmark.svg). Do not edit them by hand. Run `python3 scripts/export_branding.py` from the repository root to regenerate the SVG and 1560 × 224 PNG exports.

- `program-wordmark-white-background`: standard navy wordmark on opaque white.
- `program-wordmark-blue-background`: white wordmark and gold EU stars on opaque navy.
- `program-wordmark-reversed`: white wordmark and gold EU stars on transparent background.
- `program-wordmark-all-white`: one-color white wordmark on transparent background.

The standard transparent SVG is the canonical source itself; its PNG is [`downloads/program-wordmark.png`](../program-wordmark.png).
