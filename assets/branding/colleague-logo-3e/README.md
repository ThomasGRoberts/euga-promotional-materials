# Colleague's Logo 3e reference

`logo-3e-spec.md` and `gt-navy.png` are unchanged copies from the uploaded `logo.zip` (29 September 2026). The ZIP did not include a finished Logo 3e SVG or HTML implementation; `program-logo.png` is the older two-box program wordmark used by separate print-piece specifications.

The live reconstruction is in `branding.html`, styled by `branding-alt.css` and tuned by `branding-alt.js`. Its defaults reproduce the supplied 220 × 220 mark and 880 × 400 lockup specification. The GT PNG is described in the supplied spec as mockup artwork, not a verified official vector logo.

This is a preview sandbox only. Products continue to use `assets/branding/program-wordmark.svg`.
