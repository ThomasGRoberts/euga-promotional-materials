# Phase 1, second design pass

## Brand decisions

The supplied combined Georgia Tech / Sam Nunn School logo is used intact. The typography follows Georgia Tech guidance: DIN 2014 where available, with Roboto as the free Georgia Tech-compatible fallback. The palette uses the current core values Gold #B39051, Dark Gold #8F713D, Navy #051E39, white, and neutral grays.

## Direction 01 — Curved Earth (selected)

An orthographic Earth centered on Europe is deliberately cropped by the page. The visible planetary edge establishes global context while preserving the dense Western/Central European network and its extension to Bucharest. Twelve gold stars travel along the curvature rather than recreating the EU flag. A faint paired branch gesture suggests diplomacy and international institutions without reproducing the UN emblem.

All cities use one node style. A geography-derived minimum spanning network connects nearby cities without assigning basecamp/excursion importance or claiming a chronological itinerary.

## Direction 02 — Continental Atlas

The alternative uses an equal-area planar projection for maximum geographic and label clarity. The 12 stars arc over northern Europe as a compositional trajectory. It is cleaner for literal map reading but less distinctive as a reusable program identity because the map remains fundamentally rectangular.

## Selection

The curved-Earth direction is the stronger flyer foundation. It ties Earth, movement, EU stars, and the city network into one recognizable device while retaining geographic legibility and Georgia Tech restraint.
