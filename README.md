# EU & Global Affairs Study Abroad Promotional Materials
This is a lightweight HTML/CSS/JavaScript prototype for the Georgia Tech European Union and Global Affairs Study Abroad Program.

## GitHub Pages

The repository root is the public promotional-materials landing page. A Pages deployment workflow is included at `.github/workflows/pages.yml` and publishes automatically from `main`.

The private faculty message containing the Google Sheet editor URL is intentionally ignored by Git and is never included in the repository or Pages deployment.

## Run locally

```sh
python3 -m http.server 8765
```

Open `http://127.0.0.1:8765/` for the promotional-materials landing page that will become the GitHub Pages root.

For an in-editor preview, open `http://127.0.0.1:8765/branding.html` from the VS Code terminal or chat. The workspace enables VS Code's integrated browser for localhost links, so this preview stays in an editor tab rather than opening an external browser. The built-in **Browser: Open Integrated Browser** command can also open that URL.

- `index.html` is the organized materials hub; each product has one View link, with downloads on its own page.
- `flyer.html` is the print-flyer preview.
- `carousel-preview.html` frames the self-advancing `banner.html?autoplay=1` carousel and offers a WordPress Custom HTML embed-copy button outside the frame. Each load features two base camps, two excursions, two featured site visits, and two faculty members, interleaved with overview/curriculum/gallery content.
- `presentation-preview.html` frames the manual `banner.html?present=1` faculty presentation and offers a full-screen button outside the frame. Use arrow keys to advance. The overview/title slide opens the deck; its Stars + Globe logo uses the same live animation as the branding page, while later feature-slide logos are smaller and static. The closing slide has a transparent, scannable QR code. The deck includes all four faculty, every featured base camp and excursion, and no site-visit slides.
- `hallway.html` is a full-screen 16:9 hallway-TV banner with a Europe map, unlabeled program-city dots, the shared wordmark, and a reversed scannable QR code; a 1920 × 1080 PNG export is in `downloads/`.
- `office-door.html` is a white-background, landscape 8.5 × 5 in office-door sign with the selected shared wordmark, flyer-derived earth-limb graphic, and QR code. Its page offers an actual-size PDF and a two-up portrait Letter PDF.
- `table-tent.html` is an 8.5 × 11 in printable folding sheet with two identical outward-facing 8.5 × 3.4 in panels, a 3.75 in underside base, and a 0.45 in fastening tab. The two faces meet at the top ridge; the upper face is rotated on the flat sheet so both are upright after folding. The tab overlaps and is stapled to the base on the table-contacting underside. Fold guides remain visible in the browser preview but are suppressed in the two exported Letter PDFs.
- `branding.html` places previews of the EU/UN Flags and Stars + Globe wordmarks on either side of a two-way selector. The Stars + Globe toggle preview is a scaled clone of the settled live animation lockup, so it matches the preview below. The selector updates live products and their download links in the same browser. The concept can be downloaded as an animated GIF or static SVG.

## Architecture

- `index.html` — semantic shell and render targets.
- `styles.css` — restrained Georgia Tech-inspired visual system plus print layout.
- `app.js` — deterministic real-geography renderer adapted from the supplied reference, data loading, and motion controls.
- `assets/countries-110m.json` — local copy of the same World Atlas boundary source used by the reference.
- `data/program.json` — current Sheet-shaped Phase 1 snapshot.
- `apps-script/PhotosSync.gs` — proposed Drive-folder → Photos-tab sync implementation.
- `docs/phase-1-inspection.md` — findings, decisions, and next integration steps.

The flyer intentionally contains no photography. The standard canonical wordmark is `assets/branding/program-wordmark.svg`; the concept static lockup is `assets/branding/concept-wordmark.svg`, generated from the tuned vector geometry in `branding.html`/`branding-alt.js` by `scripts/export_concept.py`. The same concept SVG is now reused by all products at the live lockup’s 220:60 icon-to-type scale, with room for text descenders. The script also captures the live animation to `downloads/eu-stars-globe-animated.gif`. The flyer reuses the selected full lockup, with a faded header treatment. `brand-choice.js` defaults to Stars + Globe for new visitors, preserves explicit browser selections in localStorage, and switches all live logo references and available downloads. This is a per-browser choice on the static Pages site, not a global publishing setting. The standard variants in `downloads/branding/` are generated by `scripts/export_branding.py`. Both logo versions of the print PDFs are generated by `scripts/export_prints.py`; both hallway PNGs by `scripts/export_hallway.py`. The flyer’s globe uses the darker `#D9D9D4` land fill and local D3 spherical clipping to fill horizon-crossing countries cleanly without changing the projection. Run `python3 scripts/verify_globe_clipping.py` against the local preview to check geographic fill containment and circular-limb endpoints. The office-door/table-tent `assets/earth-limb-destinations.png` is an uncropped, complete globe rendered by `scripts/export_print_globe.py` from the same projection and drawing code as the flyer. It preserves the miniatures’ seven destination markers. Its expanded canvas and compensating CSS offsets preserve the previous geographic scale and position, while allowing the globe to reach its natural circular boundary or the physical panel edge. The miniatures use the approved `#D9D9D4` fill without an additional opacity fade. With the local preview running, regenerate this asset using `python3 scripts/export_print_globe.py`, then regenerate the affected PDFs. Institution-photo provenance and the one unresolved institution are documented in `photos/institutions/README.md`.

The alternate Logo 3e reference files from the colleague's ZIP are preserved under `assets/branding/colleague-logo-3e/`. The concept's vector geometry and animation code live in `branding.html`, `branding-alt.css`, and `branding-alt.js`, separate from the standard canonical wordmark. The user's tuned parameters and export provenance are recorded in `docs/concept-motion.md`. Stars and globe have separate SVG groups (`data-animation-part`) for independent motion.
